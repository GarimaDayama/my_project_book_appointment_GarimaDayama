# Concept House 🏡

Concept House is a modern, responsive front end web application and digital portal designed for architecture and interior design firms. It allows users to explore architectural portfolios, learn about design philosophies, schedule consultation appointments, and access a specialized admin dashboard via a secure login system.

## Key Features

Responsive Navigation Bar: Built using Bootstrap 4 with custom coffee brown and saddle brown styling, featuring links to Home, About Us, Services, and Contact, complete with interactive dropdown menus.


Dynamic Hero Sliders: Includes a main visual carousel showcase at the top with customized image dimensions and object fitting for a professional aesthetic.


Design Philosophy & Portfolio Modal: Highlights company values alongside an interactive portfolio carousel (`portfolio1.png`, `portfolio2.png`, `portfolio3.png`) triggered through a custom modal.


Consultation Booking System: A clean appointment scheduling modal allowing clients to submit their name, meeting topic, date, start time, and duration with selectable initial statuses (Pending/Canceled).


Interactive Quick Login & Admin Dashboard:
 Features a quick login modal supporting credential verification.


 Includes a toggleable Admin Dashboard module (`#adminModule`) that dynamically appears upon successful admin authentication to manage appointment records.




Custom Footer: A dark themed footer section featuring company information, quick service links, support links, social media icons, and contact details.

# Tech Stack

* **HTML5**: Structured semantic markup for accessibility and layout.
* **CSS3 & Custom Styling (`frontendproject.css`)**: Tailored color schemes emphasizing earth tones (maroon, beige, saddle brown, and dark charcoal) with smooth transition effects.


* **Bootstrap 4**: Responsive grid framework, modals, carousels, and navigation components.
* **JavaScript (Vanilla)**: Handles login validation, dynamic error handling, admin panel toggling, and smooth scrolling behaviors.


* **jQuery & Popper.js**: Required dependencies for Bootstrap's interactive JavaScript plugins.

## 🚀 Getting Started

To view or run this project locally on your machine, follow these simple steps:

1. **Clone or Download** the repository to your local computer.
2. Ensure all asset files (`slider1.png`, `slider2.png`, `slider3.png`, `image5.jpg`, `image3H.jpg`, `portfolio1.png`, `portfolio2.png`, `portfolio3.png`) are in the same directory as `frontendproject.html` and `frontendproject.css`.
3. Open **`frontendproject.html`** in any modern web browser (Google Chrome, Firefox, Microsoft Edge, etc.) to view the live interface.
